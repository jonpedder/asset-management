Purpose and data safeguards

Asset Management supports browsing, browser-local CSV staging, imported-record editing, and carefully gated resource updates.

Safeguards: Imported edits remain only in sessionStorage for this tab/session. A current service resource changes only after a signed-in operator explicitly clicks Save changes and the layer reports update support. Facility changes use explicit Save facility or confirmed Remove actions; demo facilities can be reviewed but never persisted. Never enter a token, password, client secret, or API key.

Sign-in and full-page redirect

The app first probes anonymous service access. If the service is private, choose Sign in. ArcGIS OAuth uses the configured full-page redirect so identity-provider handoffs do not depend on a popup or opener window.

  • The redirect URI must exactly match the URI registered with the ArcGIS OAuth application.
  • After return, the app checks the portal session and loads only data the account can read.
  • Sign out destroys the browser credential and reloads the page.
Map, current resources, filters, selection, and facilities

Resources and Facilities come from configured feature-service layers. Search and Source combine with Facility (normalized exact match), City, and ZIP filters; blank means All. Active filters are listed, and Clear filters resets them. Facility choices refresh with loaded facilities and useful asset location names.

Use row checkboxes or Select all visible for bulk selection; opening row details never toggles a checkbox. Selection survives filter changes while records still exist. Choose a loaded facility to preview its name, address, city, state, ZIP, and geometry, then explicitly choose Apply facility. Imported assets update only sessionStorage. Service assets require sign-in, update support, real object IDs, and facility geometry and use one applyEdits batch. Mixed selections update service assets first; imports stay unchanged if the service batch has failures, although ArcGIS can partially accept service updates. Geometry-only updates are disclosed when no editable location text fields are safely bound. Demo assets and demo facilities cannot be persisted. Authorized facility add/update/remove actions are capability-gated, validated, explicit writes; removal never deletes or reassigns assets.

Sorting, filtering, resizing, map symbols, and editing

Sorting: Use the compact up and down controls above the Resource list or the column controls above Facilities. Quantity sorts numerically; text values use case-insensitive natural ordering. Reset sort order restores both lists to their original loaded order. Resource rows use a multi-line card layout so the name and status remain prominent while category, department, facility, quantity, and source fit without wide horizontal columns.

Filtering: Expand Bulk facility assignment to use Search, Source, Facility, City, and ZIP filters. Filters combine, the shown count reflects the filtered result, and the tab badges retain complete Resource and Facility counts. Clear filters restores the full Resource list.

Workspace: Drag the vertical handle between the inventory and map to resize both Resource and Facility lists. Arrow keys resize the handle accessibly, Home and End choose the limits, and double-click restores the default width.

Map: Resource categories and facilities use 14-point picture symbols. ResourceName and SiteName labels appear at metropolitan scale (1:250,000) and closer. Facility popups include an Available resources by type breakdown using the current inventory assignments and available quantities. Selecting a list item zooms to its point and keeps the row highlighted with a subtle amber glow. Select the same row again, close the detail drawer, or switch inventory tabs to deselect and return to the previous map viewpoint. Native controls provide zoom, home, basemaps, layers, legend, and bookmarks.

Editing: The detail area is no longer a permanent workspace column. Select a row or map feature to open the right-side detail drawer, and close it with the × button or Escape to reclaim the full map width. Choose Edit asset or Edit facility from the drawer. The Editing Information banner is collapsed by default and explains permissions and storage boundaries when expanded. Review attributes and location, then use the explicit Save action. Add new creates a validated facility; Remove facility always requires confirmation.

Filtered reports and PDF output

Use the Reports dropdown in the inventory header and choose PDF. Every report uses the Resource filters currently applied to the list. Selecting a Facility row further scopes resource reports to that facility until the row is deselected.

  • Summary report: filtered resource and quantity totals, available totals, category counts, and the facilities represented in the current list context.
  • Resources at a facility: facility-level counts followed by a detailed list of matching resources, categories, quantities, and statuses.
  • Resources available: only filtered resources currently marked Available, Ready, Have, or In Service. The PDF includes a map of those resource points and a detailed resource list.
  • Inventory & gap status: a landscape, spreadsheet-style report modeled on the customer inventory workbook. It groups resources by department, shows headline totals, and includes Asset Type, Department, Category, Estimated Quantity, Availability, EOC Role/Use, Operator Requirement, Status, Gap Description, Procurement Priority, Estimated Unit Cost, and Notes/Source. Availability, operator, status, and priority cells use conditional colors.

The application temporarily isolates the mapped report resources for the screenshot and restores the map extent and layer visibility after export. PDF generation occurs in the browser and does not modify portal data.

CSV import, field mapping, and the 32-row customer draft

Open the Settings tab, use the Import local CSV card, and choose a CSV. Parsing occurs only in this browser. The importer identifies a plausible header row, lists its source columns, and suggests only safe exact matches after punctuation, spacing, and case normalization. Review the mapping before staging.

  1. Choose the CSV and confirm the detected header row and columns.
  2. For each target field, select an incoming column or Not mapped. Asset Type is required; other fields are optional, and one source column cannot be assigned twice.
  3. Review the first mapped records in the preview. Use Reset automatic mappings to restore safe suggestions.
  4. Choose Stage import for map. If usable location fields are present, choose whether to geocode them. Geocoding requires a second confirmation warning that the operation may consume ArcGIS credits. Accepted matches are added to the map automatically.

The known 32-row customer draft and documented exact headings continue to map automatically. Its title, summary, section, disclaimer, and blank scaffolding rows are ignored.

  • Target fields include the inventory attributes plus Location name, Address, City, State, ZIP, and Facility.
  • One imported record and at most one map point are created per data row, never per estimated quantity.
  • Settings reports loaded and ignored row counts. The map resolves staged rows against current resources, then facilities, then deterministic mocked points.
  • The selected file, mapping, preview, and staged import remain browser-local; staged normalized records remain only for this tab/session until cleared or the browser session ends.
Quantity and cost ranges

Values such as “2 - 4” remain ranges. The app preserves the raw text and calculates minimum and maximum bounds for the imported quantity KPI. Estimated unit costs are also shown as values or ranges rather than false precision.

Current service totals use service quantity fields. Imported estimates and the reported fleet benchmark are kept separate from verified current totals.

Location hierarchy, facilities, addresses, and mocks

Imported Facility or Location name values are matched against loaded facilities first; available address parts and geometry are copied. When a staged CSV contains location information, the app explicitly asks whether to geocode it and then presents a separate ArcGIS-credit warning. Geocoding runs only after both approvals; declining keeps the existing facility-match and deterministic display fallback behavior. There is no hidden bulk geocoding.

In Edit asset, retain current geometry, choose an existing facility, or enter a given address. Locate address previews only a confident match and never silently moves geometry. Saving an address requests a storage-eligible geocode and may consume services or credits. Saving a service asset also requires permission. Facility add, update, and confirmed removal are explicit service writes that require sign-in, layer capability, valid fields/geometry, and permission; they may consume services or credits.

Fleet 1,465 reconciliation

The reported fleet benchmark of 1,465 is an unverified comparison value. It is never added to service quantities or imported estimates. Reconcile it against authoritative fleet systems and current service records before using it operationally.

Settings and browser-local configuration

Settings starts local CSV imports and controls agency branding, labels, complete theme colors, resource/status colors, custom Resource and Facility icons, and startup defaults. Configuration includes public portal/OAuth identifiers, Web Map item ID and URL, Feature Service item ID and REST URL, layer indexes, map startup, and import size.

  • Each Resource category has its own icon card. Keep the original icon, reuse any icon from the 14-symbol resource catalog, or choose a custom HTTPS image/upload. Resource uploads are limited to 100 KB each and remain browser-local; Use original resets one category. A custom Facility icon replaces the default facility-management image and may be up to 300 KB.
  • Save & reload validates and stores browser-local overrides.
  • Reset defaults clears all overrides and returns to deployed configuration.
  • An image upload must be 300 KB or smaller. The preview and saved data URL remain local to this browser.
PDF and help behavior

Download help PDF generates a valid text-first PDF in-browser, paginates all topics, and uses the configured application name, subtitle, and brand colors. The download does not open a popup and has no external PDF dependency.

Troubleshooting

Sign-in loops or fails

Check the portal URL, public OAuth client ID, exact registered redirect URL, account access, and item sharing. Keep OAuth mode set to full-page redirect.

Resources or Facilities do not load

Check the Web Map URL, Feature Service REST URL, item access, and layer indexes. Diagnostics shows the effective browser configuration without exposing a credential.

Custom icons do not appear

Confirm the icon URL uses HTTPS and permits browser access, or upload a supported image no larger than 300 KB. Choose Use category icons or Use default facility icon to remove an invalid override.

Imported records are missing

Confirm the file is below the configured size limit, the correct header row was detected, and Asset Type is mapped. Resolve duplicate source-column assignments, review the mapped preview, and check ignored-row counts for draft scaffolding.

Points look inaccurate

Inspect location provenance. A mocked point is intentionally approximate. It must not be treated as current geometry.

PDF does not download

Allow browser downloads. No popup is required. Very restrictive browser policies may block the temporary download link.

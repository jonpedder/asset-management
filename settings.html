Purpose and data safeguards

Asset Management is a read-only operational inventory MVP for viewing current Resources and Facilities and previewing a customer CSV locally.

Safeguards: The application does not edit the feature service. CSV imports begin in Settings; normalized records remain only in sessionStorage for this tab/session, survive navigation to the map, and clear only when explicitly cleared or the browser session ends. Settings contain public endpoints and identifiers only; never enter a token, password, client secret, or API key.

Sign-in and full-page redirect

The app first probes anonymous service access. If the service is private, choose Sign in. ArcGIS OAuth uses the configured full-page redirect so identity-provider handoffs do not depend on a popup or opener window.

  • The redirect URI must exactly match the URI registered with the ArcGIS OAuth application.
  • After return, the app checks the portal session and loads only data the account can read.
  • Sign out destroys the browser credential and reloads the page.
Map, current resources, and facilities

Resources and Facilities come from the configured read-only feature service layers. Use the tabs, search, and source filter to narrow the inventory. Selecting a row shows source, quantity, status, location provenance, and service attributes and focuses geometry on the map.

Current service records, imported matched records, imported mocked records, and invented demo records use distinct colors. Demo data is offered only when the operational service cannot load.

CSV import and the 32-row customer draft

Open the Settings tab, use the Import local CSV card, and select the customer draft. Parsing occurs in this browser; then open the Inventory map to view the staged rows. The known 32-row customer draft includes title, summary, section, disclaimer, and blank scaffolding rows; the importer finds the real header and keeps only asset data rows.

  • Expected headings include Asset Type, Dept, Category, Est. Qty, Availability, status, cost, and notes/source fields.
  • One imported record and at most one map point are created per data row, never per estimated quantity.
  • Settings reports loaded and ignored row counts. The map resolves staged rows against current resources, then facilities, then deterministic mocked points.
  • The staged import remains only for this tab/session until you choose Clear staged import or the browser session ends.
Quantity and cost ranges

Values such as “2 - 4” remain ranges. The app preserves the raw text and calculates minimum and maximum bounds for the imported quantity KPI. Estimated unit costs are also shown as values or ranges rather than false precision.

Current service totals use service quantity fields. Imported estimates and the reported fleet benchmark are kept separate from verified current totals.

Location hierarchy, current geometry, facilities, and mocks
  1. Use a matching current resource geometry when a reliable resource match exists.
  2. Otherwise use a matching facility geometry.
  3. Otherwise assign a deterministic point near the configured map center and label it mocked.

Current geometry remains authoritative. Mocked points indicate display fallback only—not actual asset location or accuracy. Turn mocked points off with the map toggle or make that the operator default here.

Fleet 1,465 reconciliation

The reported fleet benchmark of 1,465 is an unverified comparison value. It is never added to service quantities or imported estimates. Reconcile it against authoritative fleet systems and current service records before using it operationally.

Settings and browser-local configuration

Settings starts local CSV imports and controls agency branding, labels, complete theme colors, resource/status colors, and startup defaults. Configuration controls public portal/OAuth identifiers, feature service and layer indexes, map startup, and import size.

  • Save & reload validates and stores browser-local overrides.
  • Reset defaults clears all overrides and returns to deployed configuration.
  • An image upload must be 300 KB or smaller. The preview and saved data URL remain local to this browser.
PDF and help behavior

Download help PDF generates a valid text-first PDF in-browser, paginates all topics, and uses the configured application name, subtitle, and brand colors. The download does not open a popup and has no external PDF dependency.

Troubleshooting

Sign-in loops or fails

Check the portal URL, public OAuth client ID, exact registered redirect URL, account access, and item sharing. Keep OAuth mode set to full-page redirect.

Resources or Facilities do not load

Check the HTTPS service URL, item access, and layer indexes. Diagnostics shows the effective browser configuration without exposing a credential.

Imported records are missing

Confirm the file has the expected Asset Type header and is below the configured size limit. Review ignored-row counts for draft scaffolding.

Points look inaccurate

Inspect location provenance. A mocked point is intentionally approximate. It must not be treated as current geometry.

PDF does not download

Allow browser downloads. No popup is required. Very restrictive browser policies may block the temporary download link.
